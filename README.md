# Expense Tracker

A full-stack app for recording and reviewing personal expenses.



## Features

- Add and delete expenses
- Assign a category and date
- Filter by category and month
- View total spending and category bars

## Built with

React, Node.js, Express, and SQLite

## Run locally

Start the backend in one terminal:

    cd server
    npm install
    node server.js

Start the frontend in a second terminal:

    cd client
    npm install
    npm run dev
